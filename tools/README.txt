================================================================================
                    CatalogMatch - Troubleshooting Tools
================================================================================

These scripts are for fixing common issues. You shouldn't need them if the
main SETUP.bat and RUN.bat work properly.

UTILITIES:

Create Desktop Shortcut.bat
  - Creates a desktop shortcut to RUN.bat
  - Use if you want quick access from desktop

Delete Old Snapshots.bat
  - Removes corrupted old snapshot files
  - Use if you get "no such table" errors

Fix Database.bat
  - Reinitializes database schema
  - Use if database is corrupted

Restart App.bat
  - Kills old Python processes and restarts
  - Use if app won't start (port blocked)

Start Ngrok Tunnel.bat
  - Starts secure HTTPS tunnel for off-site mobile access
  - Use after app is running, then click AUTO NGROK in CONNECT PHONE modal
