CSV BUILDER

Create product CSV files with metadata

WHAT IS THE CSV BUILDER?

The CSV Builder helps you create CSV files that link product metadata to your images for advanced matching.

HOW IT WORKS:

1. Upload a folder of product images, OR import a complete CSV directly

2. If you uploaded images, import existing product data and link it using filename matching strategies

3. Preview the linked data, then export or load directly to the main app

DYNAMIC COLUMNS: Any columns in your CSV (brand, size, color, material, etc.) will be auto-detected and available for weighted matching in the main app!
