WHAT IS THE CSV BUILDER?

The CSV Builder helps you create CSV files that link product metadata to your images for advanced matching.

HOW IT WORKS:

1. Upload a folder of product images, OR import a complete CSV directly

2. If you uploaded images, import existing product data and link it using filename matching strategies

3. Preview the linked data, then export or load directly to the main app

DYNAMIC COLUMNS: Any columns in your CSV (brand, size, color, material, etc.) will be auto-detected and available for weighted matching in the main app!

STEP 2: LINK & PREVIEW

LINK METADATA TO IMAGES:

Import a CSV file to link product metadata to your uploaded images. The linking strategy determines how image filenames are matched to CSV data.

LINKING STRATEGIES:

• Filename = SKU: Image filename matches CSV SKU field • product123.jpg → SKU "product123"

• Filename Contains SKU: Extract SKU from complex filenames • IMG_ABC-123_front.jpg → finds "ABC-123"

• CSV Has Image Column: CSV has "filename", "product", or "image" column with filenames

• Product Name Match: Fuzzy match filename to CSV "name" field (handles variations)

• Search All Fields: Check all columns including edge cases (SKU=name, etc.)

TIP: Start with "Filename = SKU" (most common). If your CSV has a column listing image filenames, use "CSV Has Image Column". For messy data, try "Search All Fields".

STEP 3: EXPORT

EXPORT YOUR CSV:

USING YOUR CSV:
