Create product CSV files with metadata

WHAT IS THE CSV BUILDER?

The CSV Builder helps you create or import CSV files with product metadata that matches your product images.

HOW IT WORKS:

1. Upload your product images OR import a CSV file directly

2. Link data to images using matching strategies, preview detected columns

3. Export or load directly to main app

DYNAMIC COLUMNS: Any CSV columns you upload will be detected and available for weighted matching in the main app!

LINK DATA TO IMAGES:

If you uploaded images, import a CSV to link product data to your images using the matching strategies below.

LINKING STRATEGIES:

• Filename = SKU: Use image filename (without extension) as SKU

• Filename contains SKU: Extract SKU pattern from filename

• Folder = SKU: Use parent folder name as SKU

• Fuzzy match: Match filename to product name
