CATALOG SNAPSHOTS EXPLAINED

What you're seeing: This shows your currently active catalog - the products that will be used for matching.

Historical vs New Products:

  • Historical: Your existing product catalog (the reference library)
  • New: Products added in this session that haven't been saved yet

Snapshots: Think of snapshots as saved versions of your catalog. You can:

  • Save the current catalog state as a named snapshot
  • Load a previous snapshot to restore that catalog version
  • Switch between different catalog versions for different matching scenarios

When you see "Loaded from:" This means you're working with a specific snapshot. Any changes you make won't affect the snapshot until you save again.

Workflow:

  1. Upload products and perform matching in the main app
  2. Click "CHANGE CATALOG" to open Catalog Manager
  3. Save current state as a snapshot or load a different one
  4. Return to main app - it automatically updates to show the new catalog

Tip: Create snapshots for different product lines, seasons, or testing scenarios!

VISUAL SIMILARITY (CLIP AI)

WHAT IS CLIP?

CLIP (Contrastive Language-Image Pre-training) is an advanced AI model that understands images at a deep level, using 512-dimensional embeddings for superior accuracy and holistic understanding.

Key Benefits:

• 512-dimensional AI embeddings for comprehensive image analysis

• Automatically analyzes color, shape, texture, and patterns

• No manual weight tuning needed - the AI handles it!

Performance:

• CPU: 5-20 images/sec

• GPU (NVIDIA/AMD): 150-300 images/sec

• Apple Silicon: 50-150 images/sec

First Run: CLIP model downloads automatically (~350MB, takes 1-2 minutes). After that, it's cached locally and loads instantly.

RESULTS

RESULTS & FILTERS:

  • Search: Filter results by product name, SKU, or category
  • Category Filter: Show only products from a specific category
  • Sort By: Order results by similarity score, category, or product name
  • Duplicates Only: Show only products with >90% similarity matches
  • Min Similarity: Dynamically adjust the minimum match threshold (filters existing results)
  • Top N Matches: Limit the number of matches displayed per product

LARGE DATASETS (10,000+ products):

  • Results are automatically split into chunks of 10,000 products for performance
  • Use Previous/Next buttons to navigate between chunks
  • Filters and search apply to the current chunk only
  • Chunk info displays at the top and bottom of results

EXPORTING:

  • CSV: Exports all match data to spreadsheet format
  • EXPORT+IMG: Creates ZIP file with images and match data
  • DUPLICATES: Generates report of potential duplicate products

CSV FORMAT GUIDE

Don't have a CSV? Use the CSV Builder to create one! It can link your existing product data to images automatically.

The CSV Builder supports multiple workflows: import existing data, export template to fill in Excel, or enter manually.

1. BASIC FORMAT

HOW TO FORMAT:

• First row: Column headers (filename, category, sku, name)

• Each row after: One product per line

• Separate columns with commas

• Filename must match your image file exactly

• Category can be left blank if using folder structure

filename,category,sku,name
product1.jpg,placemats,PM-001,Blue Placemat
product2.jpg,dinnerware,DW-002,White Plate

2. WITH CURRENT PRICE

HOW TO FORMAT:

• Add "price" column header

• Enter price as decimal number (e.g., 29.99)

• Don't include currency symbols ($, €, etc.)

• Use period (.) for decimal separator

filename,category,sku,name,price
product1.jpg,placemats,PM-001,Blue Placemat,29.99
product2.jpg,dinnerware,DW-002,White Plate,45.00

3. WITH CUSTOM METADATA

HOW TO FORMAT:

• Add any columns you need for your products

• Common columns: brand, size, color, material, description, supplier

• Columns are auto-detected and become available for weighted matching

• Column order doesn't matter - headers are used to identify fields

filename,category,sku,name,price,brand,color,material
product1.jpg,placemats,PM-001,Blue Placemat,29.99,HomeStyle,Blue,Cotton
product2.jpg,dinnerware,DW-002,White Plate,45.00,TableCraft,White,Ceramic

4. FULL EXAMPLE

COMPREHENSIVE EXAMPLE:

• Include as many or as few columns as you need

• All columns will be available for filtering in results

• In Metadata or Hybrid mode, adjust weights to prioritize certain columns

• Empty values are allowed - just leave the cell blank

filename,category,sku,name,price,brand,size,color,description
placemat-blue.jpg,placemats,PM-001,Blue Cotton Placemat,29.99,HomeStyle,Large,Blue,Premium cotton placemat
plate-white.jpg,dinnerware,DW-002,White Dinner Plate,45.00,TableCraft,10 inch,White,Classic ceramic plate
glass-set.jpg,glassware,GW-003,Crystal Wine Glass,24.99,ClearView,250ml,Clear,Lead-free crystal

IMPORTANT NOTES

  • FILENAME is the only required field - this links CSV rows to your uploaded images
  • Dynamic Columns: Add ANY columns you need (brand, size, color, material, description, etc.) - they'll be auto-detected and available for weighted matching!
  • Core fields: filename, category, sku, name, price are recognized automatically
  • CATEGORY is auto-detected from folder structure if not provided in CSV
  • All fields except filename are optional (can be left blank)
  • Already have product data? Use the CSV Builder to link existing data to your images using filename matching
  • Weighted Matching: In Metadata or Hybrid mode, adjust weights in Advanced settings to prioritize certain columns for matching
