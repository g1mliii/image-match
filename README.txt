================================================================================
                         CatalogMatch - Quick Start
================================================================================

REQUIREMENTS:
- Python 3.12 (https://www.python.org/downloads/)
- Windows 10/11
- Internet connection (for setup)

FIRST TIME SETUP:
1. Double-click: SETUP.bat (installs dependencies, ~2 minutes)
2. Wait for "Setup Complete!" message

RUNNING THE APP:
- Double-click: RUN.bat
- Desktop window opens automatically at http://localhost:8000

TROUBLESHOOTING:
- If port 8000 is blocked, see tools/README.txt for fixes
- For other issues, check tools/ folder for utilities

================================================================================
                            FILE STRUCTURE
================================================================================

RUN.bat              <- Launch the app (use this!)
SETUP.bat            <- One-time setup (run first!)
README.txt           <- This file
main.py              <- Main app file
requirements.txt     <- Python dependencies
backend/             <- App code and database
sample-data/         <- Test CSV files
tools/               <- Troubleshooting utilities
